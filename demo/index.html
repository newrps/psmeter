📊 Psmeter 데모

이 페이지는 psmeter 서버로 자동 pageview 이벤트를 전송합니다.

홈 소개 요금 연락처

네비게이션 누를 때마다 pushState 가 발생해서 새 pageview 이벤트가 전송됨 (SPA 라우팅 자동 감지).

커스텀 이벤트

JS API: window.psmeter('event_name')

설치 코드

<script src="https://your-psmeter.com/tracker/psmeter.js"
        data-server="https://your-psmeter.com"
        data-site="example.com"></script>

F12 → Network 탭에서 /api/track 요청 확인 가능.
